# Testing

This repository provides a minimal demonstration of Fisher-Flow-Matching
training for discrete sequences. The script downloads the Tiny Shakespeare
corpus and trains a tiny neural field using PyTorch. It closely follows the
algorithm summarized from
[arXiv:2405.14664v2](https://arxiv.org/abs/2405.14664).

Run the example training loop:
```bash
python3 fisher_flow_matching.py
```
